# UDC Workshop 8 — фронтенд і бекенд з AI

Домашнє завдання: зробити одну фічу **наскрізно** — UI, API, база даних,
авторизація — і перевірити те, чого не перевіряють зелені тести.

👉 **Повні інструкції — [`docs/walkthrough.md`](docs/walkthrough.md)**

## Швидкий старт

```bash
gh repo fork koldovsky/2026-udc-08-frontend-backend-hw --clone
cd 2026-udc-08-frontend-backend-hw
git checkout -b ws08/<github-username>

cd app && npm install && npm test
npm run dev          # → http://localhost:3080
```

9 зелених тестів. У застосунку можна перемикатися між двома користувачами
(Оля / Тарас) — це знадобиться.

Потрібно: Node 22+ і GitHub account. **Жодних API-ключів.**

> Бібліотеку для роботи з базою даних (`better-sqlite3`) оновлено до
> версії 13, щоб встановлення працювало й на Node 26: версія 11 не мала
> готової збірки під Node 26, і `npm install` завершувався помилкою.
> Рекомендована версія — **Node 24** (LTS), її вказано в `.nvmrc`.

## Стек — навмисно найпростіший

Express + SQLite + звичайний HTML/JS. **Без збірки й без фреймворку**: цей
воркшоп про **шви між шарами**, а не про React. Не додавайте бандлер.

## Що вже є

| Шлях | Що це |
